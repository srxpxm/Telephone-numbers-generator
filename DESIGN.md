# Number Tycoon — Signal Atelier

## Scope
A full authorial visual replacement. All original JavaScript modules remain byte-for-byte intact. The new presentation adapter only arranges existing DOM, decorates components and controls visual-only 3D/menu states. Never change economic, random-generation, timing, bank or save logic in this layer.

## Visual world
A collectible telecommunications atelier: cool porcelain surfaces, cobalt enamel, sapphire SIM objects, precise punched-chip geometry. This is a working game, not a marketing landing page. Familiar controls and navigation win over spectacle.

## Tokens
Canvas #F2F4F8; surface #FFFFFF; ink #1D2940; secondary #647088; cobalt #3657E8; pale cobalt #E9EEFF; deep blue #202D56. Positive #16765B; warning #98601B; danger #BC354A. Rarity always has a readable label in addition to color.

## Type and density
Self-hosted Onest for its compact Cyrillic forms and clear numeral construction. Tabular figures for balances, phone digits and comparisons. 4/8px spacing rhythm. Generous gaps between work areas, compact related information. Heading casing is sentence case in Russian. Display personality belongs to the SIM showroom, not every component.

## First viewport
A quiet left navigation rail; game time and wallet in the header; a wide generator with a real-time beveled SIM object, readable phone-number reels, five class choices and one unmistakable activation action. A narrow right column holds live capital and daily quests. Market and transaction information continue underneath instead of making an endless right sidebar.

## Signature interaction
The independent 3D SIM responds subtly to the pointer, class choice and generation state. This does not generate numbers or read/write game state. Pause control, reduced motion, visibility-based suspension, capped pixel ratio and static CSS fallback are required. No forced splash screen or load gate.

## Cross-surface reach
Product-like SIM art in the store; collectible number cards; calm two-column banking forms; legible statistical charts; earned/locked achievement states; clearly grouped settings and recovery tools. Mobile uses four primary destinations and an accessible More drawer.

## Reference discipline
Studied Lusion (https://lusion.co/) for controlled material lighting and large-volume/quiet-interface contrast, Bruno Simon (https://bruno-simon.com/) as a 3D-game reference (the heavy live page was not reliable in the remote browser), and the Windland case study (https://tympanus.net/codrops/2022/04/25/case-study-windland-an-immersive-three-js-experience/) for spatial scene composition. No code, layouts, models, textures, screenshots or branding from these projects are shipped. The model, textures and interface are original.

## Quality gates
All seven routes, onboarding, profile, result actions, errors, save workflows and mobile drawer are checked in the browser. Keyboard focus is visible; labels and existing accessible semantics are retained. No game-core changes. Three.js and Onest are bundled locally with license files; no runtime network is needed.

## Collection-only evolution — Collection Vault

The collection now has a deliberately darker exhibition surface inside the unchanged light/cobalt shell. This is a scoped redesign of the collection, not a new visual world for the whole game. Onest, core navigation, currency, product truth and all economic actions remain unchanged.

Materials: dark ceramic #141520, warm ivory #F0E5D7, brushed metal edges; finish colors follow the actual six rarities. One original, beveled SIM plate carries the selected number. The focal motion is an object settling into its display angle, then restrained material lighting and direct manipulation. No page-wide reveal choreography or copied reference assets.

The visual adapter is read-only with respect to game state. Existing collection rendering and action handlers stay intact. See COLLECTION.md for controls, fallbacks, reference discipline and QA scope.
