# Number Tycoon — product truth

## Platform and stack
Static browser game, Russian language. Plain HTML, CSS and JavaScript, no bundler or server required. Existing entry: index.html. Preserve direct file launch and local HTTP launch.

## Product
Collect fictional attractive telephone numbers with prefix +000. Buy SIM/eSIM cards, activate a card, inspect the generated number, keep it or sell it. The existing engine evaluates digit patterns and rarity. The collection, market, daily quests, achievements, statistics, banking and save import/export already exist.

## Non-negotiable scope
The user requested a complete replacement of visual design and UI, with all mechanics, logic and economy untouched. Preserve prices, probability tables, rarity, number generation, bank rates and terms, time progression, transactions, save formats and storage keys. Preserve all existing actions and routes. Currency is virtual GBP with the existing calculation model. All telephone numbers are fictional.

## Existing evidence
Source: the supplied README.md and original JavaScript modules. Exact audience demographics and branding preferences were not supplied and are not invented. The user requested authorial design and optional 3D, with online references used only for inspiration.

## UI quality
Desktop and mobile browser support, keyboard access, visible focus, readable contrast, reduced-motion support and a non-WebGL fallback. No online dependency for the delivered game. Visual direction is a designer proposal, not a user-approved brand commitment.
